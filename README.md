# 🚀 Redbubble Auto Publisher Pro

Automated Facebook publisher for Redbubble products with AI-powered content generation.

## ✨ Features

- 🤖 **AI Content Generation** with Groq (free, fast)
- 📸 **Smart Image Sorting** (priority products first)
- 🎬 **Auto Video & Reels Creation** from images
- 📘 **8 Content Types**: Album, Single, Carousel, Reels, Video, Text, Link, Story
- 🔥 **One-Click "Publish All"** mode
- 💯 **No-AI Fallback Templates** (always works)

## 📋 Requirements

- Python 3.8+
- Facebook Page Access Token
- Groq API Key (free)
